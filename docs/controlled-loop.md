# Controlled fast-path loop v0

Run `pnpm run jolty -- run modal` or `pnpm run jolty -- run settings`. Add `--trace` to print the complete in-memory step traces. The command loads Laya once, opens one Chromium browser, navigates to a local fixture, and executes a manually planned sequence of goals. A failed step exits nonzero and prints its trace. The human-readable summary shows each action and validation outcome.

`runControlledTask` in `@jolty/core` connects browser-state extraction, candidate filtering and retrieval, the decision provider, optional planned-value binding, Playwright execution, deterministic validation, and telemetry. Laya chooses the action and target for each step. The task supplies only a goal, any explicit form value, and expected checks. A selected action cannot be replaced with the fixture's ground-truth action. A failed decision, rejected value binding, failed action, or unmet check stops the task with distinct trace evidence. After the last check passes, the task completes deterministically; Laya's `done` output is not needed for this controlled prototype.

The `modal` task opens and confirms a dialog. The `settings` task types a planned display name and saves it; the value stays out of Laya's goal and out of the trace. These two task plans live in `apps/cli/src/controlled-tasks.ts`. They are fixed fixtures, not natural-language planning or arbitrary-site support. The runtime does not retry, recover, or call a large model. The current CLI is a narrow milestone command, not a stable public interface.

Run `pnpm run benchmark:loop` for one warmup and 10 measured serial runs per task. The duration starts before fixture navigation and ends after final deterministic validation. Browser launch, model load, page creation, and route installation are excluded. The script reports Node/Chromium/model versions, hardware, success counts, and p50/p95 task and decision latencies. On 2026-09-23, Node 25.9.0, Chromium 153.0.8010.12, and an AMD Ryzen 7 9700X completed **10/10 modal** and **10/10 settings** measured runs. Task p50/p95 was **238.0/248.7 ms** for modal and **239.5/254.9 ms** for settings. These are small local fixtures and one benchmark run; they do not establish real-site success or a speed advantage over another system.
