## Bounded import pilot

Run `python3 research/import_pilot/fetch.py` and `node --experimental-strip-types research/import_pilot/assess.ts`. The first script fetches the first three Mind2Web train trajectories and the first 12 WebChain viewer rows, then projects available HTML into a bounded offline element list. The second uses Jolty's actual candidate filter and retrieval on that projection. Source HTML is untrusted; the scripts parse it as data and never execute it. The ignored observation and report artifacts from 2026-09-24 have SHA-256 `87947c1d5f7368f4247ddba471a38682eea5a92370d02206d331411364313428` and `a47483d2ac01288e177824509f8eb4413dff2797fcc650307bae253951e4b599`, respectively. Dataset viewer rows and external HTML URLs can change; reruns must record new hashes. No raw import artifact is committed.

| Source | Sampled steps | Target identified in projected elements | Target in projected Top 10 | Offline proxy ready | Full Jolty labels admitted |
| --- | ---: | ---: | ---: | ---: | ---: |
| Mind2Web train | 37 | 28 | 11 | 11 | 0 |
| WebChain viewer | 12 | 2 | 0 | 0 | 0 |

Mind2Web had nine missing or ambiguous projected targets and 17 further targets outside Top 10. This is a **proxy** ranking over cleaned HTML: the importer assumes visibility and enabled state and does not replay actions, check postconditions, or establish stable current-site URLs. It must not be reported as live Jolty Recall@10 or training yield. WebChain had five rows without a usable snapshot (including launch actions) and seven with snapshots but no independent task goal. Two of its projected target IDs were found, but action-derived titles would leak the answer and were not used as goals. A future WebChain probe should read a bounded trace SFT shard, recover the actual task instruction, and verify that its DOM/AX target survives Jolty extraction before admission. The current result does not justify bulk import.

## Executed development collection pilot

`JOLTY_RESEARCH_CORPUS_VERSION=9 JOLTY_RESEARCH_DEV_CASE_IDS=playqa-login-email,playqa-field-text,playqa-wizard-next-after-details,upex-basic-input,upex-email-input,upex-autocomplete-menu node --experimental-strip-types apps/cli/src/research/collect-research.ts artifacts/development-collection-pilot.json` runs only allowlisted **train** cases and requires a separate output path. The collector records case-level target-location failures instead of aborting the development probe. It cannot select test cases through this mode. The 2026-09-24 run used Play QA and UPEX Dojo, both separate from all reserved test origins. All **6/6** cases executed and passed independent postconditions; **6/6** targets were in Top 10, with ranks 1, 1, 1, 1, 1, and 6. It rejected **0** labels for ambiguous or unidentifiable targets and **0** for other collection failures. Actions were four `type` and two `click`. The content digest was `511e3f18152a1d016055839c770807a5945bb7ba5b3a3d649613bc738c45f573`. This small selected sample confirms the development collector path, not general retrieval recall or rejection prevalence.

## Frozen blind-site matrix and reference gate

The [blind manifest](../research/blind_sites/manifest.json) was frozen on 2026-09-24 **after** all reference flows passed. Its source hashes bind the case definitions, validator runner, and local HTML. It contains six sites, five observed template families, two flows per site, and **72 unique goal/state decisions**. Their browser-state hashes alone have **56 unique values**; repeated browser snapshots with different goals count as different decisions, and the two counts must not be conflated. In three fresh 1280×800 Chromium contexts per flow, **36/36** reference flows passed independent postconditions and **216/216** reference targets were present in Jolty's Top 10. The ignored execution artifact SHA-256 is `62db485d0371661d0355f1ac61d0b8e5b29d8a42742267a00c0b8915e3b286c9`. Reproduce with `node --experimental-strip-types apps/cli/src/research/blind-reference.ts 3 artifacts/blind-reference.json`; compare source hashes before using a rerun as evidence. No model was scored, no threshold was selected using this test, and v9 remained sealed.

These are **reference labels**, not model results. Public-page content and third-party behavior can change; a failed future replay invalidates that case until a separately versioned replacement is prepared without looking at model scores. H Y R and ScrapingCourse block third-party requests; both shop flows disable JavaScript because dynamic DOM reordering caused stale element indices in the initial pilot. This load policy is part of the frozen case contract and must be applied identically to every model. The shop's cart page gave inconsistent state and was excluded; the bottle flow validates the add-to-cart notice instead. The watch flow validates URL fragments and quantity without submitting an order.

The four public sites remain **exposure unknown** because v10s has no effective training manifest. Their distinct origins and page structures do not prove template novelty relative to its training data. Dispatch and Ledger have demonstrably new source provenance and distinct templates; the full set contains more than the required three observed template families. WebChain and BrowserGym remain development/training investigations and are absent from the blind manifest. The subsequent one-time [model comparison](m13-blind-comparison.md) used the same 72 captured decisions. A 72-decision set can detect failures but cannot substantiate a 99% accepted-decision precision claim.
